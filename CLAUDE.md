# Сайт Екатерины Глебовой — инструкции для Claude Code

- Источник правды по дизайну: `design_handoff_site/Ekaterina Glebova Site.dc.html` + `design_handoff_site/README.md`. Это HTML-референс, не продакшн-код — он пересобран как статический сайт в корне репозитория.
- Стек: Vite + чистые HTML/CSS/JS. Без фреймворков, без UI-библиотек.
- Структура: `index.html` (вся страница), `privacy.html`, `src/style.css`, `src/main.js`, `public/assets/` (оригинальные изображения, без обработки), `public/favicon.svg`.
- Иконки: Lucide инлайнятся на сборке через `{{icon:name}}` в HTML (плагин в `vite.config.js`).
- Настройки: `.env` — `VITE_TELEGRAM_URL` (все кнопки записи ведут в Telegram) и `VITE_SITE_URL` (canonical / og:url / og:image).
- Палитра: терракота — `--accent #a3502c`, `--accent-l #e09a76` (на тёмном), кнопки `--btn #8c4425`; все токены в `:root` в `src/style.css`, источник — `design_handoff_site/README.md` → Design Tokens. Голубого в проекте больше нет.
- Тексты переносить дословно, не переписывать.
- Брейкпоинты: phone <600, tablet portrait 600–1024, tablet landscape 1025–1366 + (pointer: coarse), desktop — остальное. Hero — 4 отдельных лейаута. Брейкпоинт выставляется в `<html data-bp>` инлайн-скриптом в `<head>` и `src/main.js`.
- Фото hero (`hero-cutout.png`) визуально не обрабатывать: без масок, блюра, фильтров, обрезки. Изображения не сжимать и не конвертировать (решение владельца).
- Отличия от референса по решению владельца: мягкая тень за головой в hero убрана во всех 4 лейаутах; на телефоне фото hero отдалено (голова не касается шапки, видны оба плеча) — см. `.hero--phone .hero__par`.
- Заголовок hero заменён по решению владельца (31.10.2026): «Помогаю найти внутреннюю опору, лучше понять себя и увереннее пройти период перемен»; акцентным цветом выделено «внутреннюю опору, лучше понять себя». Переносы на десктопе/планшетах подобраны под ширину колонки (самая длинная строка ≤ 13em при 600).
- Текст hero (решение владельца): во всех 4 лейаутах h1 → подзаголовок → кнопка идут одной колонкой (`.hero__stack`). Отступ между ними `--hero-gap`: 10px на телефоне и растёт с лейаутом. Подзаголовок всегда вдвое меньше h1 (`--hero-h1`); на телефоне h1 30px / подзаголовок 15px, h1 переносится свободно. На телефоне и планшете-портрете контент чёрной плашки в потоке — высота hero по контенту, 4 карточки всегда внутри плашки с отступом снизу; параллакс текста там отключён.
- Все анимации сохранить; уважать `prefers-reduced-motion`; курсор/magnetic/spotlight — только для мыши.
- Формы нет: запись идёт через Telegram. Модальное окно из референса не переносилось.
- Перед коммитом проверять все 5 размеров: 1553, 1366, 1024, 768, 390.
- Деплой: GitHub Actions (`.github/workflows/deploy.yml`) → GitHub Pages на каждый push в `main`. В настройках репозитория Pages → Source: «GitHub Actions». Публичный адрес сайта — в `.env` → `VITE_SITE_URL`.
