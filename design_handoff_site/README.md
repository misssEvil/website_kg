# Handoff: сайт психолога Екатерины Глебовой (лендинг)

## Overview
Одностраничный сайт-лендинг частного психолога. Цель — запись на консультацию (модальная форма). Дизайн утверждён для 5 размеров: десктоп, планшет горизонтально, планшет вертикально, мини-планшет, телефон.

## About the Design Files
`Ekaterina Glebova Site.dc.html` — **дизайн-референс, сделанный в HTML**, а не продакшн-код. Он показывает точный вид и поведение. Задача — **пересобрать его как обычный статический сайт** (рекомендуется: Vite + чистые HTML/CSS/JS, без фреймворка — одной страницы для этого достаточно) и задеплоить через GitHub.

Как открыть референс: запустить локальный сервер в этой папке (`npx serve .`) и открыть `.dc.html` в браузере. Он работает на собственном рантайме (`support.js`): разметка с `{{ }}`-плейсхолдерами, стили инлайн, логика — класс `Component` в `<script type="text/x-dc">` в конце файла. В продакшне это не нужно — переносите разметку, стили и логику в обычные HTML/CSS/JS.

Не переносить:
- `support.js`, `image-slot.js`, теги `<x-dc>`, `<helmet>`, `<sc-if>`, `<sc-for>` — служебные для редактора. `<image-slot>` → обычный `<img>` (или `<picture>`).
- Переключатель «Устройство» (prop `device`, объект `DEVICES`, обёртка-«сцена» `#page-wrap` с рамкой) — только для ревью дизайна.

## Fidelity
**High-fidelity.** Цвета, шрифт, размеры, отступы, тексты и анимации финальные. Тексты не переписывать — переносить дословно (включая авторское «Конфеденциально» в hero — уточнить у заказчика перед релизом).

## Единицы
Hero сверстан абсолютным позиционированием в `cqw` (1cqw = 1% ширины контейнера с `container-type: inline-size`), посчитанных от ширины референс-кадра. В продакшне можно оставить `cqw` на обёртке страницы или заменить на `vw` (обёртка во всю ширину — значения совпадают). У текста есть нижние пороги `max(Npx, …cqw)`.

Остальные блоки — обычная flex/grid-вёрстка (`max-width:1320px`, боковые отступы `clamp(20px,5cqw,72px)`). Всё, что меняется по брейкпоинтам, собрано в объекте `rs` в `renderVals()` — превратить в media-query-оверрайды.

## Interactions & Animations
Общий easing: `cubic-bezier(.16,1,.3,1)`.
- **Reveal** (`data-reveal`, IntersectionObserver, threshold .12): `up` — opacity 0→1 + translateY 56px→0 (1.1s/1.3s); `clip` — `clip-path: inset(100% 0 0 0)` → `inset(0)` (1.6s). `data-delay` в мс.
- **Hero intro**: строки заголовка выезжают снизу (translateY 110%→0, 1.3s, шаг 110ms); подзаголовок/кнопка/фичи — fade-up 30px (1.2s, +550ms, шаг 150ms); фото — только opacity 0→1 (2.2s).
- **Parallax**: фото hero `translateY(scrollY*0.15)`, текст hero `*0.08`; фото в секциях (`data-par`) ±6%. Hero-фото ещё слегка смещается за мышью (−10px).
- **Magnetic buttons** (`data-magnetic`): сдвиг к курсору (dx·0.18, dy·0.3).
- **Count-up** (`data-count`): 2s, ease-out-expo, запятая как десятичный разделитель.
- **Blobs** (`data-blob`): мягкие белые пятна, бесконечный дрейф 16–24s.
- **Marquee**: translateX 0→−50%, 38s / 60s, бесконечно.
- Всё отключается при `prefers-reduced-motion: reduce`. Курсор, spotlight и magnetic — только для `pointerType === 'mouse'`.
